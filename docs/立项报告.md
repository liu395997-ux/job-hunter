# 立项报告：自动化求职工具

## 一、题目

自动化求职工具 —— 招聘职位数据可视化分析与个性化推荐系统

## 二、摘要（不超过 200 字）

针对招聘信息海量分散、求职筛选费时的痛点，本项目面向学生求职者，构建自动化求职工具。系统爬取招聘网站的大数据相关职位信息，经清洗标准化后存入数据库，从薪资、技能需求、企业画像等维度挖掘分析，结合用户简历画像，采用 TF-IDF 余弦相似度、随机森林回归、KMeans 聚类等算法，给出个性化岗位推荐与求职报告，以 Streamlit Web 应用可视化展示全流程，帮助求职者高效了解行业待遇、定位合适岗位。

## 三、调研（同类产品对比）

| 产品 | 数据来源 | 推荐依据 | 可复现性 / 局限 |
| --- | --- | --- | --- |
| BOSS 直聘 / 智联招聘 | 站内职位与用户行为 | 登录后的浏览、投递历史 | 依赖平台账号与行为数据，算法不可见，无法离线复现 |
| LinkedIn Job Match | 站内简历与技能图谱 | 结构化简历画像匹配 | 面向海外数据，数据封闭，不支持自定义数据集 |
| 拉勾 / 猎聘推荐 | 单一平台职位 | 浏览历史与收藏 | 功能聚焦单平台，缺少薪资、技能等多维分析 |

本项目差异点：数据源可配置、推荐基于公开职位文本可离线复现、面向校园求职场景提供薪资分析 / 技能图谱 / 自动报告等多维能力。

## 四、需求列表（用户故事）

1. 作为求职者，我想输入技能、城市、学历与期望薪资，以便看到匹配度最高的岗位。
2. 作为求职者，我想查看不同城市、学历、经验的薪资分布，以便评估自身待遇水平。
3. 作为求职者，我想查看热门技能及组合关系，以便规划学习方向。
4. 作为求职者，我想自动获得新增岗位与匹配提醒，以便及时投递。
5. 作为组长，我想一键运行「爬取→清洗→分析→展示」全流程，以便演示与验收。
6. 作为评审，我想查看清洗前后对比与数据质量报告，以便验证数据的可靠性。

## 五、技术方案

- 系统架构：采集层 → 数据层 → 算法层 → 展示层 → 自动化层（分层解耦、可独立替换）。
- 开发平台与语言：Python 3.12，本机 Windows 环境，uv / venv 管理依赖。
- 框架与库：requests（爬虫）、pandas（清洗）、scikit-learn（算法）、Streamlit（Web 界面）、matplotlib / wordcloud / networkx（可视化）、SQLite（存储）。
- 算法：TF-IDF + 余弦相似度（个性化推荐）、随机森林回归（薪资预测）、KMeans 聚类（岗位画像）、词频 + 共现分析（技能图谱）。
- 开发流程：TDD（需求文档先行、测试先行）、ruff 代码质量门禁、git 协作。

## 八、可行性分析

### 技术可行性

团队成员具备《程序设计》《Python》《数据分析》等前置课程基础；关键链路已在本机验证（320 条样例数据全流程跑通，44 个测试通过）。真实招聘网站存在反爬风险，已设计「真实爬取失败自动降级样例数据」方案，保证演示链路不中断。

### 团队可行性

5 人分工与模块边界清晰，通过 CSV / SQLite 解耦；采用 git 提交记录、例会纪要、代码审查保证协同；答辩随机抽题，要求每位成员深度掌握自己负责的模块，并对 AI 生成的代码逐行理解。
