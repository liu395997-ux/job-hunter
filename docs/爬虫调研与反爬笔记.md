# 爬虫调研与反爬笔记

## 目标站点

智联招聘公开职位搜索接口（课程项目常用数据源）：

```text
GET https://fe-api.zhaopin.com/c/i/sou
    ?kw=数据分析
    &cityId=530        # 北京；城市 ID 映射见 spider/config.py
    &p=1
    &pageSize=90
```

页面入口：https://www.zhaopin.com/

## 实测结论（2026-08-30）

### 现象

- 接口 TCP/HTTPS 可达，返回 HTTP 200；
- 返回体为合法 JSON，`code=200`、`apiCode=200`，但 `data.results=[]`、`numTotal=0`、`numFound=999999`；
- 每次响应携带新的 `taskId`，`isVerification=0`，疑似服务端风控的“空结果”应答，而不是正常空数据。

### 尝试过的对策

| 尝试 | 结果 |
| --- | --- |
| 仅 User-Agent（Chrome 126） | 200 + 空结果 |
| 追加 Referer: https://www.zhaopin.com/ | 200 + 空结果 |
| Session 先访问首页取 Cookie（无 Cookie 下发） | 200 + 空结果 |
| 追加 x-requested-with: XMLHttpRequest、Accept: application/json | 200 + 空结果 |

### 原因推断

1. 该接口已升级风控，对数据中心 / 代理 IP 直接返回空结果；
2. 或接口新增了由页面 JS 动态生成的签名参数（如 `at` token），纯 requests 无法获得；
3. 智联近年来对无登录匿名抓取收紧，属于公开资料中常见的“接口存活但数据加锁”场景。

### 后续可尝试方向

- 改用浏览器自动化（Playwright / 本机浏览器控制）模拟真实用户访问搜索页；
- 换用 51job / BOSS 直聘，或直接申请站点开放 API / 使用公开数据集；
- 在校园网 / 家用网络（非机房出口 IP）重试，排除 IP 风控；
- 演示时以 `data/sample/sample_jobs.csv` 兜底，保证链路可跑通。

## 工程化处理

- 爬虫模块（`spider/`）已按可替换解析器设计：站点配置在 `spider/config.py`，解析器在 `spider/parsers.py`，调度策略（BFS/DFS）在 `spider/scheduler.py`；
- 命令行：`python scripts/run_crawler.py --site zhaopin --keyword 数据分析 --cities 北京 --pages 1`；
- 全失败时退出码非 0，并提示“使用样例数据：python scripts/run_pipeline.py”；
- `scripts/run_pipeline.py` 默认优先读取 `data/raw/jobs_zhaopin.csv`（真实爬取成功时），否则回退样例数据；
- 反爬与接口变更只影响 `config.py` / `parsers.py`，清洗、存储、分析、UI 全部不受影响。
